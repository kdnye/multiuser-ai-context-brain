# Ask for a page in the shared area

Use this to share a process, reference list or guide from your own notes with everyone.

Only the shared-editor role can publish to the shared area, and an editor reviews each page before publishing it.

## Steps
1. Write the page in your own area first. Ask your assistant to use the matching template: tutorial, how-to,
   reference or explanation.
2. Ask an editor to review it for the shared area. Say which roles it is for, so it lands on their portals.
3. The editor checks it for sensitive data, cites its sources, sets an owner and a review date, and publishes it.

## If something goes wrong
- The page mentions pay, health, HR matters or passwords: it cannot go in the shared area. Link to the system of
  record instead.
